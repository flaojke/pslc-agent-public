# delivery-progress Specification

## Purpose
Показывает фактический прогресс PSLC Agent по этапам с отдельной готовностью кода и приёмки, сохраняя проверяемые изображения состояния после каждой вехи.

## Requirements

### Requirement: DP-001 Evidence based roadmap
Дорожная карта SHALL иметь единый версионируемый источник со статусом кода, проверки и ссылками evidence для каждого этапа. Внешне непроверенное MUST не считаться production-ready; проценты или сроки без оснований не публикуются.

#### Scenario: Code without corporate environment
- **WHEN** реализация прошла fixtures, но нет реального IdP/Confluence/LLM или стенда
- **THEN** код отмечен отдельно от ожидающей внешней приёмки

### Requirement: DP-002 Milestone image
После каждой завершённой вехи SHALL формироваться актуальное PNG с датой/временем Москвы, версиями и сделанными/следующими этапами, передаваться в текущем чате и сохраняться в истории snapshots. latest SHALL соответствовать последнему snapshot.

#### Scenario: Milestone completion
- **WHEN** OpenSpec-изменение реализовано и проверено
- **THEN** статус обновлён по evidence, изображение построено и показано пользователю

### Requirement: DP-003 Continuous authorized delivery
Разработка SHALL продолжаться по зависимостям без повторных согласований уже разрешённых действий. Нужные внешние параметры SHALL запрашиваться асинхронно, а независимые задачи продолжаться. Непройденные внешние проверки MUST оставаться видимыми, без вымышленного закрытия всего MVP.

#### Scenario: Missing endpoint
- **WHEN** корпоративный endpoint ещё не предоставлен
- **THEN** доступные реализация и локальные проверки продолжаются, а внешняя проверка отмечена ожидающей
