# network-discovery Specification

## Purpose
Обнаружение доступных кандидатов в явно выбранной внутренней сети с честным покрытием и без скрытого управления.

## Requirements

### Requirement: ND-001 Explicit bounded network discovery
Администратор SHALL запускать «Сканировать сеть» только для явно показанного локального частного IPv4 CIDR до1024 адресов. Публичные, loopback, link-local и multicast диапазоны MUST отклоняться. Сканирование SHALL быть ограниченным по времени/параллелизму и не запускаться при открытии страницы.
#### Scenario: Inspect before scanning
- **WHEN** администратор открывает сканирование
- **THEN** видит локальные диапазоны, адреса/лимиты и подтверждает конкретный CIDR; широкая сеть требует явного уменьшения
#### Scenario: Unsafe target
- **WHEN** передан публичный диапазон или превышен предел
- **THEN** соединения не создаются и запрос отклоняется

### Requirement: ND-002 Observable incomplete coverage
Сканирование SHALL показывать прогресс, отмену и найденные адреса с методом обнаружения. Отсутствие ответа MUST не объявляться отсутствием компьютера. Порты MUST не доказывать ОС, тип ПК/сервер или установленный агент. Результаты SHALL быть ограниченными RAM metadata с явным TTL.
#### Scenario: Filtered host
- **WHEN** firewall скрывает все проверяемые порты
- **THEN** интерфейс объясняет неполноту обнаружения, не объявляя полный парк найденным
#### Scenario: Cancel scan
- **WHEN** администратор отменяет сканирование
- **THEN** новые проверки не запускаются, частичные кандидаты помечены; рестарт не возобновляет scan

### Requirement: ND-003 Candidate is not managed
Для кандидата SHALL предлагаться явное создание профиля подключения с выбранными ОС/типом/разрешениями. До успешной установки/enrollment кандидат MUST не появляться среди управляемых целей и не получать команды. Выбор кандидата SHALL не устанавливать ПО автоматически.
#### Scenario: Add candidate
- **WHEN** оператор выбирает найденный адрес
- **THEN** готовится профиль установки; управляемый узел появляется только после обычного bound enrollment с credential
