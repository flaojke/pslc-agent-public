# PSLC Agent 0.19.0 — публичная поставка

Выпуск 15.11.2026: [скачать приложение и исходники](https://github.com/flaojke/pslc-agent-public/releases/tag/v0.19.0).
Один install ZIP без весов моделей и подготовленный SourceZIP. Модели загружаются только по явной кнопке в настройках.

67 целевых тестов,4 инструкции, TypeScript/Vite, чистая установка/Resume с32 pinned dependencies,13 экранов и независимая пересборка SourceZIP прошли проверку. Все7 файлов прошли GitHub size/SHA256 readback; каждая ссылка проверена анонимным bounded GET без авторизации.

[Контрольные суммы и фактические ссылки](RELEASE_0.19.0.json). Подробная приёмка — VERIFICATION.md в Assets. Реальные LLM/download/inference, корпоративный OpenWebUI, службы и production-нагрузка не приняты. Windows AppControl не обходился, VM не создавались.

Тег v0.19.0 указывает на проверенный коммит исходников. Запись о доставке и завершённое OpenSpec-изменение добавлены отдельным последующим коммитом документации; тег и готовые архивы не перемещаются и не переписываются.
