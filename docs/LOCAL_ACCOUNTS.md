# Локальные учётные записи —0.10.0

Сотрудники входят с локальными учётными записями. Системная УЗ создаётся при первом запуске accounts режима: логин **admin**, пароль **admin**. Это общеизвестный стартовый пароль. Смените его до сетевого использования. В «Учётные записи» можно изменить его; обязательный дополнительный шаг при первом входе не навязывается.

После входа открывается «Основной раздел» с одним промптом. Кнопка «Учётные записи» внизу меню: каждый сотрудник может изменить свой пароль, администратор — создать УЗ/назначить роли/устройства, сбросить пароль и отключить сотрудника. Новые пароли≥8символов, логины латиницей/цифрами/._-, без регистра. Роли: operator, auditor, reviewer, platform_admin. Device scope задаётся явно: выбранные IDs или «Все узлы». Пустой scope не даёт доступ к парку. Confluence отложен, knowledge permissions не требуются.

Bootstrap выполняется только при пустой таблице accounts. Рестарт/обновление не возвращает admin/admin и не снимает disable. Последнего активного администратора нельзя отключить/лишить admin роли через API. Пароли хранятся только как salted scrypt(N16384,r8,p1,salt16,key32), в API/события не возвращаются. Системный admin получает прежнюю local ownership для сохранения истории; остальные сотрудники имеют отдельные opaque IDs и не получают чужие планы/вывод.

Cookie sessions — HttpOnly/SameSiteStrict, Secure на HTTPS, RAM≤15min. Login/logout/mutations требуют точный Origin из PSLC_PUBLIC_ORIGIN. Default origin http://127.0.0.1:8787, поэтому открывать именно этот адрес; при другом имени/HTTPS его следует настроить явно.5неверных попыток по имени/IP блокируют следующие на30секунд. Logout/restart/password/role/disable revision отзывают доступ. Изменение собственной УЗ завершает её прежние сессии; войти заново. Scope/disable повторно проверяются на confirmation/dispatch, queued задания могут получить access_revoked.

Обычный запуск load_settings использует accounts. Явный PSLC_AUTH_MODE=oidc сохранён для будущего SSO, но не нужен сейчас. Явный PSLC_AUTH_MODE=local — только совместимый development bearer для старых тестов/CLI, не fallback: accounts не принимает прежний operator token. Если в приватном окружении уже задан другой mode, выставить PSLC_AUTH_MODE=accounts. Секреты других сотрудников не печатать/не помещать в Git; передавать выбранным способом.

Schema6 сохраняет узлы/credentials/историю/permissions и добавляет account verifiers/grants + enrollment profiles. Защищённый metadata backup содержит хеши-верификаторы, а не пароли. Restore поддерживает schema6 и известный старый schema5 snapshot, но не восстанавливает RAM sessions. OIDC identities автоматически не присваиваются локальным сотрудникам. AD/SSO и Confluence в readiness помечены отложенными, не обязательным подключением.
