# Полный установочный архив агента

«Устройства» → «Подключить устройство» либо профиль найденного кандидата → выбрать ОС, явный тип и разрешения → «Подготовить подключение» → «Скачать установочный ZIP». Браузер проверяет SHA256 скачанных байтов по ответу сервера.

Windows/Linux x64 ZIP содержит native0.7.0 со всеми runtime-библиотеками и лицензиями, config.json, README, launcher, проверку SHA256 состава, public key/подписанный native manifest и шаблон службы. Python на узле не требуется. Исходная native-поставка проверяется Ed25519 verifier до экспорта и повторно по байтам при записи ZIP. Повреждение/неполный пакет, чужой/истёкший/использованный профиль блокируют выдачу.

Одноразовый код регистрации показан отдельно и действует10минут. Его, действующие credentials и существующую identity архив не содержит. URL экспорта — временный owner-bound handle. Сервер формирует один архив за раз в защищённой временной директории; файл удаляется после отдачи либо уборкой. На клиенте ZIP появляется только по явному скачиванию.

Распаковать в постоянную отдельную папку. Windows: verify.ps1, затем start.ps1 -Enroll; Linux: chmod +x start.sh native/pslc-agent; ./start.sh --enroll. Код вводится скрыто штатным native-агентом. Повторный запуск без enrollment использует ту же identity. Распаковка не устанавливает службу и не расширяет допуски.

Проверьте server, state, CA и opt-ins в config. Loopback127.0.0.1 подходит только машине приложения. Для удалённого парка настройте доступный HTTPS PSLC_PUBLIC_ORIGIN; CA передайте отдельно, без insecure fallback. Существующие identities при установке не перезаписываются.

Служба — явное отдельное действие с правами администратора и выделенной сервисной УЗ. Windows-скрипт создаёт остановленную LocalService службу; Linux unit требует проверки путей/прав. QA подпись и SHA256 не заменяют корпоративное доверие. SCM/systemd на рабочих машинах в этой вехе не устанавливались.

Реально проверены скачанные ZIP обеих платформ, PowerShell checksum script, Windows standalone health и Linux standalone health в Docker/WSL2. Это не приёмка физического Linux. Native resources включаются в оба серверных Full/Lite варианта; финальная сборка этих вариантов отслеживается отдельно.

Распаковку Windows можно выполнить штатным [Expand-Archive](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.archive/expand-archive); обход корпоративной ExecutionPolicy не требуется и не предлагается.
