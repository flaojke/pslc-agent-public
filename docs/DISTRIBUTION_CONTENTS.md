Приложение поставляется одним Lite ZIP без весов. Full, parts и сборщик нескольких частей для 0.19.0 не предлагаются. После установки откройте **Настройки → Модели → Скачать** у выбранной модели. Проверка размера и SHA256 должна завершиться до использования; частичный или изменённый файл не активируется. Есть прогресс, отмена и явный повтор. Запуск и выбор каталожного ID сами по себе не начинают загрузку.

Ранее скачанные проверенные модели и сохранённые профили сохраняются. Новый архив не содержит пользовательский cache и не меняет автоматически выбор локальной модели/OpenWebUI. Source.zip — комплект разработчика, а не приложение с моделью.

## Системные условия

Python 3.12+ x64 нужен отдельно. Зависимости устанавливаются по requirements.lock.txt из доверенного package index либо wheelhouse. Для локальной CPU-модели рекомендуются 32 ГБ RAM; GPU не обязателен. Docker/VM не являются условием native-запуска.

Smart App Control/App Control может запретить runtime даже при целых весах и совпадающих SHA. При local_runtime_policy_blocked не отключайте защиту и не скачивайте целые веса повторно как способ обхода: используйте разрешённый runtime или явно настроенный OpenWebUI. Файлы не подтверждают inference, качество ответов или право выполнять команды.

## Проверка и первое включение

Каждый архив требует проверки состава, лицензий, исключения рабочих данных, manifest и SHA256. Старые архивы без проверки публичной поставки не объявляются готовыми публичными релизами. Сверьте SHA256 до распаковки и проверьте manifest по [инструкции](INSTALL_RELEASE.md).

В пустой базе создаётся общеизвестный **admin/admin**. **Обязательно смените пароль до сетевого использования**, ограничьте доступ и настройте доверенный TLS. Существующие пароли при рестарте не сбрасываются. Не открывайте административный интерфейс в недоверенную сеть.

SHA256 подтверждает байтовую целостность, а не безопасность или корпоративную сертификацию. Тестовые ключи и подписи не заменяют производственную PKI. Проверка ОС, прав служб, сети, TLS, резервирования и организационных допусков остаётся отдельным этапом.
