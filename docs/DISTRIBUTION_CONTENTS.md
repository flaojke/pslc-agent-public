# Состав поставок

Исходный код проекта распространяется по Apache-2.0, см. корневой LICENSE. Сторонние компоненты и веса моделей сохраняют собственные лицензии и notices; лицензия проекта их не заменяет.

Каждый новый архив требует отдельной проверки состава, лицензий, секретов, manifest и SHA256. Старые архивы, не прошедшие такую проверку, не распространяются как публичные релизы.

Full добавляет веса модели; Lite требует отдельной загрузки весов. Runtime и native-компоненты требуют отдельных лицензий/attribution. Python-зависимости устанавливаются по lock-файлу из доверенного package index либо подготовленного wheelhouse. Source checkout сам по себе не содержит готового Web, runtime или модели.

В пустой базе создаётся общеизвестный admin/admin. Смените пароль до сетевого использования; существующие пароли при рестарте не сбрасываются. Не открывайте административный интерфейс в недоверенную сеть.

SHA256 проверяет целостность, а не безопасность или корпоративную сертификацию. Тестовые ключи и подписи не заменяют доверенную производственную PKI. Проверки конкретной среды, подпись, права служб, TLS, резервирование и допуски остаются ответственностью развёртывания.
