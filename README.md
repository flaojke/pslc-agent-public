# PSLC Agent

Экспериментальная система поддержки и администрирования Windows/Linux: разбор проблемы, подготовка точного плана, подтверждение, выполнение узловым агентом и проверка результата.

Версия исходников: **0.19.0**. Код и проверка целостности не подтверждают готовность к production. Сеть, TLS/PKI, права служб, выбранные модели и организационные допуски требуют отдельной проверки.

## Скачать и установить

Архивы и контрольные суммы: [Releases v0.19.0](https://github.com/flaojke/pslc-agent-public/releases/tag/v0.19.0).

- **[Lite.zip](https://github.com/flaojke/pslc-agent-public/releases/download/v0.19.0/PSLC-Agent-0.19.0-Lite.zip)** — приложение с готовым Web, CPU runtime и native-компонентами, **без весов моделей**.
- **[Source.zip](https://github.com/flaojke/pslc-agent-public/releases/download/v0.19.0/PSLC-Agent-0.19.0-source.zip)** — подготовленные исходники для разработчиков с готовым Web, без runtime, native binaries и весов.

Веса не включаются в архивы и не скачиваются при запуске. Администратор открывает **Настройки → Модели → Скачать**, дожидается проверки SHA256 и явно выбирает модель. Есть прогресс, отмена и повтор. Сохранённые модели и профили OpenWebUI не удаляются и не переключаются автоматически. Full/parts/сборщик нескольких частей для этой поставки не нужны.

Для native Windows нужны **Python 3.12+ x64** и свободное место. Для локальной CPU-модели рекомендуются **32 ГБ RAM**; GPU не обязателен. При OpenWebUI модель выполняется у выбранного провайдера. Docker и VM для приложения не требуются.

Сверьте SHA256, распакуйте Lite и из его каталога выполните в PowerShell:

```powershell
py -3.12 scripts/verify_release.py .
.\scripts\install-release.ps1
.\scripts\start-release.ps1
```

Соблюдайте принятую ExecutionPolicy, не обходите запрет скриптов. Python-зависимости устанавливаются из доверенного package index либо wheelhouse. Полный порядок — в [инструкции развёртывания](docs/INSTALL_RELEASE.md).

Откройте http://127.0.0.1:8787/. В новой пустой базе создаётся **admin/admin** с широкими правами. **Обязательно смените этот общеизвестный пароль до сетевого использования.** До этого используйте только loopback. Не публикуйте административный интерфейс в Интернет. Перезапуск не сбрасывает существующий пароль.

## Модели и ограничения Windows

Поддерживаются локальная CPU-модель и настроенный OpenWebUI. Каталог содержит Qwen3.5-4B и меньшую Qwen3.5-2B; веса загружаются отдельно по кнопке. Ключ OpenWebUI вводится в защищённое поле интерфейса; не сохраняйте его в Git или публичных issue.

Проверенный GGUF не означает работающий runtime. Smart App Control/App Control могут блокировать EXE/DLL с local_runtime_policy_blocked или 0xc0e90002 / Bad Image. Повторное скачивание целых весов это не исправляет. Не отключайте защиту Windows: используйте разрешённый runtime либо явно выберите и проверьте существующий OpenWebUI. Автоматического переключения провайдера нет.

## Возможности и границы

- Диалоги, точный выбор устройств, подтверждаемые планы и проверка результата.
- Агенты Windows/Linux и ограниченное обнаружение частной IPv4-сети.
- Локальные учётные записи, роли и области доступа.
- Откат объявленных ресурсов и согласованные расписания; полное восстановление ОС не гарантируется.
- Один API; до 5 активных шагов в сеансе, 20 удалённых заданий на парк и 500 зарегистрированных устройств. Это не заявление о проверенной production-нагрузке.

Модель не получает самостоятельного разрешения на команды. Сохраняются точное подтверждение, права сотрудника и независимые разрешения узла. Неизвестный исход требует сверки перед повтором.

Исходные журналы, полный вывод и контекст модели остаются в ограниченной RAM. Типизированные метаданные, зашифрованный baseline узла и явно сохранённые шаблоны расписаний имеют отдельные правила хранения.

## Разработка

Git checkout и автоматические GitHub Source code ZIP/TAR не содержат готовый Web, runtime, native binaries или веса. Они отличаются от подготовленного Source.zip в Releases. Не переносите рабочую .local, ключи или личные файлы разработчика.

Нужны Python 3.12+ x64 и Node.js с pnpm. Создайте отдельное Python-окружение, установите requirements.lock.txt, выполните pnpm install --frozen-lockfile и pnpm build. Проверки: python -m pytest и python scripts/generate_product_guides.py --check. Runtime/native-компоненты берите из проверенного Lite той же версии; веса — через интерфейс.
