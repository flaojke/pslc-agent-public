# Security

PSLC Agent is experimental administrative software. Do not expose it directly to the Internet or use it as evidence of production security approval.

The initial account in an empty database is admin/admin. This is a public default, not a secret. Change its password before network use, restrict access, configure trusted TLS and keep node opt-ins disabled until explicitly required. Existing passwords are not reset on restart.

Use synthetic data when reporting an issue. Do not post credentials, raw logs, private source material or sensitive environment details in public issues. A dedicated private vulnerability-reporting channel has not yet been established; request a private contact without including exploit details or secrets.
